# سایت‌کاو — نسخه ۴.۰ (وب‌اپ یکپارچه: خزش + نمایش داده‌ها)

ابزار خزش هوشمند سایت‌ها و سامانه‌های دارای لاگین — مخصوص ویندوز.
**همه‌چیز در یک برنامه:** هم شروع خزش، هم دیدن کامل داده‌ها، عکس‌ها، فایل‌های HTML و جدول‌ها — بدون نیاز به پنجره tkinter.

## تازه‌های نسخه ۴.۰ — شروع خزش از داخل وب 🚀

دیگر لازم نیست پنجره‌ی tkinter باز کنید؛ از همان صفحه‌ی وب که داده‌ها را می‌بینید، خزش تازه را هم شروع کنید (پورت 5002):

- **صفحه‌ی «🚀 شروع خزش جدید»:** آدرس سامانه + نام کاربری/موبایل + رمز + پوشه خروجی +
  تنظیمات پیشرفته (سقف صفحه‌ها، سقف صفحه‌بندی هر فهرست، تأخیر، «فقط این صفحات»)
- **پیشرفت زنده در همان صفحه:** نوار پیشرفت، شماره صفحه‌ی فعلی، آدرس صفحه‌ی در حال خزدن،
  **لاگ زنده رنگی** و زمان سپری‌شده — بدون نیاز به ترمینال
- **دکمه‌های کنترل از وب:** «توقف خزش» و «⏭ رد کردن صفحه‌ی فعلی» — همان قابلیت‌های
  رابط گرافیکی، این‌بار داخل مرورگر
- **پایان خزش = اتصال خودکار نمایشگر:** بعد از پایان خزش، داشبورد و گالری و جدول‌ها
  خودش به خروجی تازه وصل می‌شود؛ چیزی دستی تنظیم نمی‌شود
- **ورود دومرحله‌ای هم ساده شد:** اگر سامانه کد پیامکی خواست، پیامش در لاگ زنده می‌بینید؛
  کد را در همان پنجره‌ی مرورگر وارد و تأیید کنید (برنامه تا ۳ دقیقه منتظر می‌ماند)
- **گزینه‌های همان رابط گرافیکی:** رد شدن خودکار از صفحات فیلتر (کد ملی/پرونده/رهگیری)،
  اسکرین‌شات، فایل‌های جانبی (عکس/CSS/JS)، خزش تازه یا ادامه، ورود دستی برای کپچا

### اجرا — دستور کامل PowerShell

یک بار نصب (اگر هنوز نصب نکرده‌اید):

```powershell
cd D:\Projects\site-crawler-v3
pip install -r requirements.txt
python -m playwright install chromium
```

هر بار اجرا:

```powershell
cd D:\Projects\site-crawler-v3
python viewer.py
```

مرورگر خودش باز می‌شود روی `http://127.0.0.1:5002` — یا خودتان باز کنید.

**دست‌های کوتاه‌تر (کپی کنید):**

```powershell
cd D:\Projects\site-crawler-v3; python viewer.py
```

یا ساده‌تر: **دوبار کلیک روی `start_web.bat`** (یا `run_web.bat`).

اگر می‌خواهید از گوشی یا رایانه‌ی دیگریِ همان شبکه هم باز شود:

```powershell
python viewer.py --host 0.0.0.0 --port 5002
```

سپس در دستگاه دیگر آدرس `http://آی‌پی-رایانه:5002` را باز کنید
(آی‌پی رایانه را با `ipconfig` ببینید). اگر ویندوز پرسید، اجازه‌ی دسترسی در شبکه‌ی خصوصی را بدهید.

> نکته: اگر پورت 5002 اشغال بود: `python viewer.py --port 5050`

## تازه‌های نسخه ۳.۴ — نمایشگر وب فلسکی 🎉

حالا داده‌های ذخیره‌شده را **در یک وب‌اپلیکیشن زیبا** ببینید — روی پورت **5002**:

- **داشبورد گرافیکی:** آمار کامل (صفحه‌ها، جدول‌ها، ردیف داده‌ها، تصاویر، لینک‌ها)
  همراه نمودار میله‌ای بزرگ‌ترین مجموعه‌داده‌ها و نمودار حلقه‌ای ترکیب متن‌ها
- **صفحه‌ها:** فهرست و جست‌وجوی همه‌ی صفحه‌های خزیده‌شده + جزئیات هر صفحه:
  متن‌های برداشت‌شده، لینک‌ها، جدول‌ها و **اسکرین‌شات همان لحظه**
- **مجموعه‌داده‌ها:** مرور همه‌ی جداول داده (ds_*) با جست‌وجو در همه‌ی ستون‌ها،
  صفحه‌بندی و **دانلود اکسل/CSV برای هر مجموعه**
- **جدول‌های HTML:** نمایش کامل جدول‌های استخراج‌شده + خروجی اکسل/CSV هر جدول
- **گالری تصاویر:** همه‌ی اسکرین‌شات‌ها و تصاویر سایت در یک نمای شبکه‌ای با بزرگ‌نمایی
- **فایل‌های HTML:** مرور ذخیره‌ی HTML هر صفحه **داخل خود برنامه** (iframe)
- **جست‌وجوی سراسری** در عنوان‌ها، متن‌ها، لینک‌ها و جدول‌ها
- **لاگ خزش و پاسخ‌های API** ثبت‌شده در حین خزش
- **ساخت دوباره‌ی export.xlsx:** اگر فایل اکسل خروجی خالی مانده (مثلاً وقتی خزش
  نیمه‌کاره متوقف شده)، با یک کلیک خروجی کامل (۲۹ شیت) از دل دیتابیس ساخته می‌شود
- **پوسته‌ی تاریک/روشن** + فونت وزیرمتن + رابط کاملاً راست‌به‌چپ — بدون نیاز به اینترنت

اجرا:

```
دوبار کلیک روی start_web.bat
یا:  python viewer.py
سپس مرورگر را باز کنید:  http://127.0.0.1:5002
```

اگر دیتابیس را خودکار پیدا نکرد، مسیر `site_data.db` را در صفحه‌ی «تنظیمات»
(یا با `python viewer.py --db "C:\مسیر\site_data.db"`) وارد کنید —
یا کلاً از صفحه‌ی «شروع خزش جدید» یک خزش تازه اجرا کنید تا همه‌چیز خودکار تنظیم شود.

## تازه‌های نسخه ۳.۳

- **رفع گیر کردن روی صفحات «کد ملی»: دیگر مدام کد ملی امتحان نمی‌شود** —
  صفحاتی که فقط یک فیلد «کد ملی / کد پرونده / کد رهگیری» با دکمه
  «تایید / استعلام / جستجو» دارند، دیگر به‌اشتباه صفحه ورود تشخیص داده
  نمی‌شوند؛ علت گیر کردن و پر شدن فیلد کد ملی در نسخه‌های قبل همین بود.
- **دکمه «⏭ رد کردن صفحه فعلی» در برنامه:** هر لحظه از خزش که صفحه‌ای به
  هر دلیلی گیر کرد، این دکمه را بزنید؛ صفحه فعلی رها می‌شود و خزش به
  صفحه بعدی ادامه می‌دهد (حتی وسط تلاش برای ورود یا انتظار).
- **تشخیص قوی‌تر صفحات فیلتر:**
  - اگر فرم کد ملی داخل **iframe** باشد هم پیدا و رد می‌شود
  - جدول‌های اطلاعاتی کوچک (مثل پنل کاربر در نوار کنار) دیگر مانع تشخیص نیستند؛
    فقط جدول‌های داده‌ای واقعی (گرید) مانع رد شدن‌اند
  - برای سایت‌های React/Angular که دیر رندر می‌کنند، صفحه یک‌بار دیگر هم بررسی می‌شود
- **«رد شدن خودکار از صفحات فیلتر» حالا پیش‌فرض روشن است** — حتی با تنظیمات قدیمی.

## تازه‌های نسخه ۳.۲

- **رد شدن خودکار از صفحات فیلتر:** صفحاتی که فقط فرم «کد ملی» / «کد پرونده» /
  «کد رهگیری» و مانند آن دارند (بدون جدول داده) شناسایی می‌شوند و از آن‌ها فقط
  لینک‌ها دنبال می‌شود — دیگر وقت صرف پر کردن فرم و صفحه‌بندیِ صفحات خالی
  نمی‌شود. تیک آن در بخش «حالت‌های ویژه» است. فهرست کلیدواژه‌ها
  در `config.json` با کلید `crawl.filter_keywords` قابل افزودن است.
- **رد کردن/ادامه دادن از داخل خود مرورگر:** هنگام «توقف پیش از برداشت»، یک
  نوار شناور در پایین صفحه مرورگر ظاهر می‌شود با دو دکمه
  **«⏭ رد کردن این صفحه»** و **«✔ ادامه بده»** — دیگر لازم نیست به پنجره
  برنامه برگردید؛ از همان مرورگر تصمیم بگیرید.

## تازه‌های نسخه ۳.۱

- **کپی/چسباندن در همه فیلدها درست شد:** راست‌کلیک → کپی/برش/چسباندن، و
  میان‌برهای Ctrl+V / Ctrl+C / Ctrl+X / Ctrl+A — حتی وقتی چیدمان صفحه‌کلید
  فارسی است (مشکل نسخه قبل همین بود؛ حالا با کد فیزیکی کلید کار می‌کند)
- **رفع توقف برنامه بعد از وارد کردن کد پیامکی:** پنجره کد حالا همیشه روی
  همه پنجره‌ها باز می‌شود، شمارش‌معکوس دارد، دکمه «خودم در مرورگر وارد کردم»
  دارد و در صورت پذیرفته نشدن کد، خودش کد جدید می‌پرسد (تا ۵ تلاش)
- **دیالوگ‌های جاوااسکریپت سایت** (مثل «کد اشتباه است») خودکار بسته می‌شوند
  و دیگر جلوی ادامه برنامه را نمی‌گیرند
- **تنظیمات فرم بین اجراها ذخیره می‌شود** — دیگر لازم نیست آدرس و مشخصات را
  هر بار تایپ یا جای‌گذاری کنید

## شروع سریع

**۱) وب‌اپ یکپارچه (پیشنهاد ما):** دوبار کلیک روی `start_web.bat`، یا در PowerShell:

```powershell
python viewer.py
```

سپس در مرورگر: `http://127.0.0.1:5002` → منوی **«🚀 شروع خزش جدید»** →
آدرس سامانه + یوزر/پس را بدهید و خزش را ببینید؛ بعد از پایان، همه‌ی داده‌ها
(دیتابیس، عکس‌ها، فایل‌های HTML، جدول‌ها) در همان برنامه نمایش داده می‌شود.

**۲) رابط گرافیکی tkinter (روش قبلی):** دوبار کلیک روی `run_gui.bat`
یا در PowerShell:

```powershell
python crawler_gui.py
```

در پنجره باز شده:
1. **آدرس سامانه + نام کاربری/موبایل + رمز عبور** را وارد کنید
2. در بخش «چه صفحاتی خزیده شود؟» می‌توانید خزش را به بخش خاصی محدود کنید
   (مثلا فقط `/Reports` — هر خط یک عبارت؛ خالی یعنی همه صفحات)
3. در بخش «محل ذخیره‌سازی» پوشه خروجی و زیرپوشه‌های اسکرین‌شات / HTML /
   CSS-JS-قالب را انتخاب کنید
4. «شروع خزش» را بزنید — گزارش زنده در همان پنجره دیده می‌شود

### ورود دومعلی (کد پیامکی)
اگر سامانه اول موبایل بخواهد و بعد کد تأیید بفرستد، برنامه خودش مرحله کد را
تشخیص می‌دهد و **پنجره‌ای برای وارد کردن کد باز می‌کند** (همیشه روی همه
پنجره‌ها، با شمارش‌معکوس ۱۰ دقیقه‌ای). سه راه ادامه دارید:
1. **تأیید و ادامه** — کد را در برنامه وارد کنید؛ خودش در سایت ثبتش می‌کند
   (جعبه‌های رقم‌به‌رقم React/Angular هم پشتیبانی می‌شود)
2. **خودم در مرورگر وارد کردم — ادامه بده** — کد را خودتان در پنجره مرورگر
   تایپ می‌کنید؛ برنامه فقط منتظر موفقیت ورود می‌ماند
3. **رد کردن** — انصراف

اگر کد پذیرفته نشود، پنجره دوباره باز می‌شود (تا ۵ تلاش) و شماره تلاش در
پیام دیده می‌شود. برای کپچا یا جریان‌های پیچیده‌تر، گزینه «ورود دستی در
مرورگر» را بزنید. بعد از یک ورود موفق، سشن ذخیره می‌شود و اجراهای بعدی
بدون نیاز به کد ادامه می‌یابند.

### توقف برای اعمال فیلتر (صفحات گزارشی)
تیک «توقف پیش از برداشت صفحات» را بزنید: برنامه قبل از برداشت هر صفحه توقف
می‌کند، شما در پنجره مرورگر فیلترها را اعمال می‌کنید و بعد دکمه
**«ادامه»** را می‌زنید. اگر صفحه‌ای به دردتان نبود، **«رد شدن»** بزنید تا از
آن صفحه عبور کند. (این حالت مرورگر را خودکار قابل‌مشاهده می‌کند.)

## خروجی‌ها

| خروجی | محل |
|---|---|
| اکسل همه جداول (`export.xlsx` — یک شیت برای هر جدول) | پوشه خروجی |
| **اکسل جداگانه به نام هر صفحه** (پوشه `excel-per-page`) | پوشه خروجی |
| اسکرین‌شات کامل صفحات | `screenshots` |
| کد کامل HTML هر صفحه | `html` |
| CSS، جاوااسکریپت، تصاویر و قالب هر صفحه | `assets/<نام صفحه>/css , js , img` |
| دیتابیس کامل SQLite (`site_data.db`) | پوشه خروجی |
| لاگ کامل اجرا | `crawl.log` |

در دیتابیس: `pages`, `page_texts`, `html_tables`, `table_rows`, `links`,
`datasets`, `api_responses` (پاسخ‌های JSON ایجکس = داده خام سایت‌های
React/Angular) و جدول‌های `ds_*` (داده ساختاریافته هر فهرست با ادغام
صفحه‌بندی و حذف تکراری).

## پشتیبانی از سایت‌های React / Angular / Vue

- منتظر رندر کامل JS می‌ماند (networkidle) قبل از برداشت
- جداول و لینک‌های داخل **iframe** هم برداشت می‌شوند
- پاسخ‌های JSON درخواست‌های AJAX/Fetch ضبط می‌شوند (`api_responses`)
- ورود دومعلی و فرم‌های موبایل‌محور پشتیبانی می‌شوند

## خط فرمان (برای کارهای خودکار)

```powershell
python crawler.py                    # اجرا طبق config.json
python crawler.py --fresh --headed   # شروع از صفر با مرورگر مرئی
python crawler.py --manual           # لاگین دستی (کپچا)
python crawler.py --export-only      # فقط ساخت اکسل از دیتابیس موجود
python crawler.py --max-pages 50     # سقف صفحات
python crawler.py --cdp              # اتصال به کروم واقعی خودتان (فایروال سازمانی)
```

## نکات فایروال سازمانی

اگر «دسترسی مسدود» (FortiGate و مانند آن) دیدید، بهترین راه:
1. کروم را با این دستور باز کنید:
   `"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="%TEMP%\cw-profile"`
2. سپس: `python crawler.py --cdp`
یا در config مقدار `browser.channel` را `"chrome"` بگذارید.
